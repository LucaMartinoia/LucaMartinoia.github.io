## Rebase

When performing a rebase:
1. Keep all current website content as is, don't modify the textual content of markdown and HTML files.
2. Import all new corrections, in terms of CSS, JS and Jekyll/Ruby settings, but remember to append any modification already present (e.g. in the _layout)
3. When some option is new and wasn't present before, inform the user and wait for instruction.
